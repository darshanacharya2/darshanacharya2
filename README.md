## 🌟 Featured Projects

### 🐛 [Namma Reshme](https://github.com/darshanacharya2/Namma-Reshme)

A Kotlin-based Android application that acts as a digital sericulture guard. It helps farmers compare temperature and humidity readings with ideal conditions for each silkworm growth stage and provides actionable guidance.

**Tech:** Kotlin • Android Studio • Android SDK

### 🩺 CNN-Based Radiological Abnormalities Detection System

A full-stack medical imaging application using CNN and YOLOv8 to identify and highlight potential abnormalities in radiological images and generate downloadable reports.

**Tech:** React • Node.js • Express • Python • CNN • YOLOv8
